# v0.19.1 · 修复坚果云 WebDAV 同步

- 重新发布 v0.19.1，包含以下全部修复；已安装旧 v0.19.1 的设备可直接覆盖升级。
- 修复坚果云 WebDAV 同步和上传备份时，对已有目录重复发送 `MKCOL` 导致 HTTP 403 的问题。
- 兼容未提供强 ETag 的 WebDAV 服务，发布前检查远端版本，发布后读回校验，并保留独立历史快照。
- 简化设备同步：一个 WebDAV 远程目录对应一份数据，移除远程账号 ID 输入；自动识别唯一一份旧数据并沿用原路径和备份历史。
- WebDAV 测试连接成功或失败后改为 Toast 提示。
- 日常同步包含订阅源、阅读状态及 APP 设置，不上传文章正文；手动备份仍可选择包含文章。

缺少强 ETag 时，兼容模式无法保证多台设备同时写入的原子性，建议错开同步；检测到远端变化时会提示重试。

本次修复通过 **90 项单元测试**、GitHub Release 的 lint 与正式签名 APK 构建验证。尚未使用真实坚果云账号联调。

版本号为 **0.19.1**，Android versionCode 为 **52**（原发布包为 51）。
