# v0.19.0 · WebDAV 轻量同步与独立文章备份

WebDAV 日常同步只传输订阅源、分组、APP 偏好和阅读状态。文章由各设备自行抓取，避免把正文与本机缓存带入每次同步。

## 同步与备份

- 同步外观、字体选择、字号、阅读布局、交互和语言等 56 项 APP 偏好，支持逐项合并与恢复默认值。
- 已读、收藏、稍后读状态独立保存。新设备尚未抓到文章时先保留状态，后续抓取时自动应用，不生成空文章。
- 清理本机文章缓存会保留阅读状态，不会删除其他设备的文章；订阅源和分组的删除仍参与同步。
- 手动备份与日常同步使用独立文件及合并基线。“备份文章内容”默认关闭，开启后仅影响手动备份；已下载的解析全文可另行选择备份。
- 轻量备份替换恢复时保留仍订阅源的正文缓存，完整备份则同时替换文章。恢复前继续保存本机完整恢复副本。

## 升级与兼容

- 配对设备请一同升级至本版。新格式使用独立的 v3 同步与备份文件，旧客户端无法与新格式实时互通。
- v1/v2 旧备份仍可恢复；首次同步从旧备份提取订阅及阅读状态，保留旧备份文件。
- 数据库由 v10 升至 v11，新增独立阅读状态表，不改写已有文章。
- APP 偏好全局生效，会影响本机所有账号。登录凭据、证书、当前账号、指定浏览器、字体文件、网络与本机清理策略不参与同步；外部字体文件需另行导入。
- WebDAV 服务器仍需支持强 ETag 和条件 PUT。旧文件与不可达分块暂不自动回收，远程历史保留 20 个先前版本，本地恢复副本保留最近三份。
- Feedly、Inoreader、Miniflux 和 Tiny Tiny RSS 仍处于实验阶段，尚未使用真实账号联调。

本次功能调整已通过 **77 项单元测试**及 GitHub Debug 的 lint 与 APK 构建；详细同步范围见 `docs/webdav-sync.md`。
