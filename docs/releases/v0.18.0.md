# v0.18.0 · 账号同步加固与 WebDAV 备份升级

## 阅读与服务

- 接入 Feedly、Inoreader、Miniflux 和 Tiny Tiny RSS，支持账号配置、文章同步及已读 / 收藏状态写回。这四类服务的订阅管理在各自网页端完成。
- 阅读状态加入持久队列，断网后重试；刷新时保留尚未上传的本地操作。
- 全文搜索覆盖标题、摘要、RSS 正文和已缓存全文，并保留筛选与排序。
- 账号设置显示同步进度、最后成功时间、失败原因与重试入口。

## WebDAV 备份与恢复

- 配置、远程账号身份和同步记录按账号隔离，可通过相同的远程账号 ID 配对设备。
- 升级 v2 备份格式，加入删除同步、冲突预览、压缩分块、校验和与条件写入，阻止损坏备份和并发覆盖。
- 恢复可选择合并或完全替换，支持远程历史回退、可选离线全文，以及恢复前自动保存的本地恢复副本。
- 本地恢复副本可不联网恢复；保留 20 个远程历史版本和最近三份本地恢复副本。
- 本地 RSS 账号支持双向同步与恢复；服务端账号可上传备份，请在本地 RSS 账号中恢复。

## 修复与安全

- 修复账号切换导致的后台同步、全文缓存、清理、分组计数、通知和 Widget 归属问题。
- 清理与归档使用事务，修复重复归档和恢复时间问题，保留收藏与稍后读文章。
- 凭据迁移到 Android Keystore + AES-GCM；解密失败保留原密文并提示重新连接。备份排除密码和 token。
- 默认使用系统 TLS 与主机名校验；私有证书按服务器显式导入，HTTP 连接需单独开启。
- 修复 Compose、资源及 WorkManager API 使用问题，补齐数据库迁移与同步回归测试。

## 验证与兼容说明

- 功能改动已通过 63 项单元测试及 API 34 独立模拟器上的 8 项设备测试，覆盖凭据迁移 / 进程重启 / 密钥丢失、跨账号导航、分页释放和 10,050 篇未读文章的通知打开。
- 新接入的四种服务仍处于实验阶段，尚未使用真实账号联调；API 权限、套餐和旧文章状态写回限制以服务端为准。
- WebDAV 服务器需支持强 ETag 和条件 PUT；旧 v1 备份可读取，配对设备请一同升级。远程不可达旧分块暂未自动回收，使用记录时间解决冲突依赖设备时钟。
- 百万篇文章、低磁盘空间及其他 Android 版本 / 厂商硬件 Keystore 尚需专项验证。完整实现与测试对应见 `docs/improvement-plan.md`。
