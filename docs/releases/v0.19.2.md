# v0.19.2 · 整理 WebDAV 设置与同步记录

- 按现有设置页的样式整理 WebDAV：首页保留同步操作与状态，连接信息和可选备份分别进入详情页。
- 可选备份集中管理备份范围、上传与恢复，远程版本和本地恢复副本在独立列表查看。
- 操作历史移至独立页面，明确标注仅保留最近 50 条，点击记录查看详情，避免记录堆在首页底部。
- 修复点击“立即同步”后，RSS 自动同步在数据没有变化时仍重复上传、生成不同版本并增加操作记录的问题。仍会同步实际变更，失败记录也会保留。
- 操作历史区分“自动同步”和“立即同步”，切换页面时保留同步结果、冲突与重试信息。

本次更新通过 **96 项单元测试**、GitHub Release 的 lint 与正式签名 APK 构建验证，并在 Android 模拟器检查中文、返回导航、深浅色、大字号、横屏及历史记录上限。

下载本页附带的签名 APK 安装。版本号为 **0.19.2**，Android versionCode 为 **53**，可从 v0.19.1 直接覆盖升级。
