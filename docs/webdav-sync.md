# WebDAV 同步与备份

日常同步用于跨设备延续订阅和阅读体验；文章内容由 RSS 抓取并保存在本机。手动备份用于迁移或保留无法重新获取的历史内容。

## 连接与设备

一个 WebDAV 远程目录对应一份数据。在各设备填写相同的服务器地址、登录信息和远程目录即可使用，不需要填写远程账号 ID。

开启“RSS 同步后自动同步”后，RSS 刷新完成会检查 WebDAV。如果本机和远端数据已一致，自动同步不会重复上传或新增操作历史；有实际变化或同步失败时，历史中会显示“自动同步”，与手动点击的“立即同步”区分。是否跳过取决于数据内容，不按固定时间间隔忽略请求。

WebDAV 首页保留同步操作与状态，连接信息、可选备份、操作历史分别进入详情页。可选备份集中管理备份范围、上传与恢复，远程版本和本地恢复副本分别在独立列表查看。操作历史仅保留最近 50 条，超过后自动移除最早记录，不在首页展开；此记录上限不影响备份内容与版本。

新配置使用固定的内部存储位置；已有数据继续使用原路径。新设备以及从未成功上传过的旧配置，会自动识别目录下唯一一份旧同步数据，沿用原来的分块和备份历史。如果存在多份旧数据，则停止自动选择，避免将不同数据混合；空目录不算一份数据。新旧存储位置不会自动删除或移动。

| 数据 | 日常同步 | 手动备份 |
| --- | --- | --- |
| 订阅源、分组、单源阅读偏好 | 包含 | 包含 |
| 外观、字体选择、字号、阅读布局、交互及语言偏好 | 包含 | 包含 |
| 已读、收藏、稍后读状态 | 包含 | 包含 |
| 文章标题、摘要、RSS 正文、历史文章 | 不包含 | “备份文章内容”开启后包含，默认关闭 |
| 已下载的解析全文 | 不包含 | 文章备份与离线全文备份均开启后包含 |
| 登录凭据、证书、指定浏览器、字体文件、网络及本机清理策略 | 不包含 | 不包含 |

APP 偏好是全局设置，应用同步或恢复的偏好会影响本机所有账号。账号登录信息和当前选中的账号不随之改变。外部字体文件需要在目标设备另行导入。

## 阅读状态与本地文章

阅读状态以订阅 URL 和文章链接关联，独立持久化。新设备即使还没有正文，也会保存同步到的标记；之后 RSS 抓到该文章时会套用已读、收藏和稍后读状态，不会创建只有状态的空文章。

第一次同步时，刚抓取文章的默认状态（未读、未收藏、未标记稍后读）可以接受另一台设备的已有标记。两端均有实际不同标记且无法确定共同版本时，仍须明确处理冲突。偏好按设置项合并，支持恢复为默认值。

清理本机缓存会保留阅读状态，不会把其他设备的文章删除。删除订阅源、分组仍会参与同步。RSS 不一定继续提供历史文章，需要长期保留的正文应主动启用文章备份。

## 手动恢复

手动备份与日常同步独立保存，各自保留版本，不会因为开启文章备份而使自动同步上传正文。

- 合并恢复：保留本地条目，冲突时选择采用哪一端。
- 替换恢复：以备份中的订阅、阅读状态及 APP 偏好为准。不含文章内容的备份保留仍订阅源的正文缓存；含文章内容的备份同时替换文章，即使该备份没有文章。
- 应用远程变更或恢复前，仍会在本机保存完整恢复副本，包含已缓存全文，最多保留三份。
- 服务端账号仍由对应 RSS 服务管理订阅和阅读状态；可以手动备份，再恢复到本地 RSS 账号。

## 兼容与存储

v1/v2 旧备份可以恢复。第一次使用新日常同步时，会从旧备份提取订阅及阅读状态，旧文章正文不会被写进新同步文件，旧备份文件不会被覆盖。

新格式使用独立的 `readyou-sync-v3.json` 与 `readyou-backup-v3.json`，同步和备份也分别保存本机合并基线。各设备需要一同更新；旧客户端继续操作旧文件，无法与新格式实时互通。

服务端返回强 ETag 时，使用 `If-Match` 条件写入，阻止并发覆盖。缺少强 ETag（包括弱 ETag 或未加引号的值）时仍可同步：先校验旧数据、保存独立快照，发布前比较远端版本，发布后读回校验，检测到变化即提示重试且不应用到本机。此兼容模式不能保证两台设备同时写入时的原子性，最好错开同步；历史快照继续保留。首次发布仍使用 `If-None-Match: *`。

Room 数据库新增阅读状态表，版本从 10 升至 11，不改写已有文章。远程历史保留 20 个先前版本；旧文件与不可达分块仍不会自动回收。
